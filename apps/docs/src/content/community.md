# Get involved

## Discord

Join the conversation, ask questions, and share feedback on [Discord](https://discord.gg/YRTyJd6Qx).

## Issues and pull requests

Report bugs and request features in [GitHub issues](https://github.com/santoshyadavdev/angular-devtools/issues). To contribute code, start with the [development setup](/contributing/development).

## Sponsor

If the devtools help your work, please consider [sponsoring the project on GitHub](https://github.com/sponsors/santoshyadavdev). See the current [sponsors](/sponsors).
